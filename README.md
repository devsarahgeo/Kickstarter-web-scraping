# Startup Prediction Model

## 🧭 Executive Summary
This project focuses on extracting real-world startup campaign data from Kickstarter using BeautifulSoup and Selenium, followed by cleaning, structuring, and exploring the data for early insights into what makes a campaign successful.

### 💼 Business Problem
Aspiring entrepreneurs often struggle to identify key factors that contribute to a successful crowdfunding campaign. The goal of this project is to collect, analyze, and understand trends in Kickstarter projects to uncover what differentiates successful campaigns from failed ones.

---

## ⚙️ Methodology (2005 Dataset)

### 1. Data Collection
- Used Selenium for dynamic page navigation and scrolling.
- Used BeautifulSoup for parsing and extracting HTML content.
- Collected details such as project title, category, goal, pledged amount, backers, and project status.
  
### 2. Data Cleaning & Processing
- Removed duplicates and incomplete records.
- Exported the cleaned dataset to CSV for further analysis.

### 3. Exploratory Analysis (EDA)
- Performed summary statistics on success vs failure rates.

---

## 🧠 Skills & Tech Stack
- **Languages & Libraries** – Python, Pandas
- **BeautifulSoup & Selenium (Web Scraping)**
  
---

## 📈 Results
- Extracted a structured dataset of Kickstarter projects for analysis.
- Identified campaigns that reached or exceeded their funding goal.
  
## 💼 Business Recommendation
Focus on moderate funding goals and well-defined categories, as they exhibit higher campaign success rates. The scraped dataset can further support predictive analysis to guide future startups in setting realistic targets.

## 🚀 Outcome
Gained hands-on experience in automated web scraping, data preparation, and insight generation — key steps in transforming raw online data into actionable startup intelligence.
